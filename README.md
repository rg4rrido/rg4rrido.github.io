# rg4rrido.github.io

Código fuente de mi blog personal: [rg4rrido.github.io](https://rg4rrido.github.io)

Writeups de CTFs, notas de mi HomeLab y el registro de mi ruta de
certificaciones minetras me especializo en la ciberseguridad ofensiva.

## Sobre este repo

El sitio está construido con [Jekyll](https://jekyllrb.com/) y el tema
[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy), desplegado
automáticamente en GitHub Pages con GitHub Actions en cada push a `main`.


Los posts siguen la convención de categorías `[Plataforma, SO/Tipo]`
(p. ej. `[HackTheBox, Linux]`) para que se agrupen jerárquicamente en
`/categories/`.
